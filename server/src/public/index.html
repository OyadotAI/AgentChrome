Step 2

Connect to this server

Open Oya Browser. The setup screen asks for a server URL and API key. Enter:

Server URL:  wss://browser.oya.ai/ws
API Key:     your-api-key

Once connected, the browser appears in the dashboard. You can see it, send commands, and get the MCP endpoint.

Step 3

Connect your AI tool

Go to the dashboard, click your browser, switch to the MCP Tools tab, and copy the config. Or use this template:

// Cursor, Claude Desktop, Windsurf, or any MCP client
{
  "mcpServers": {
    "oya-browser": {
      "url": "https://browser.oya.ai/mcp/BROWSER_ID",
      "transport": "streamable-http",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}

Replace BROWSER_ID with your browser's ID from the dashboard. The AI can then call analyze_page, click, type, and all other tools.
