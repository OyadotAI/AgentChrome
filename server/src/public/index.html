For AI tools

Connect Claude, Cursor, or any MCP client

Once your browser is connected, configure your AI tool with the MCP endpoint from the dashboard:

{
  "mcpServers": {
    "oya-browser": {
      "url": "https://browser.oya.ai/mcp/YOUR_BROWSER_ID",
      "transport": "streamable-http",
      "headers": { "Authorization": "Bearer YOUR_API_KEY" }
    }
  }
}
